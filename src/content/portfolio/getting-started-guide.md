This getting started guide was produced for the launch of a new NI Source Measure Unit (SMU) product, giving engineers the information they need to unbox, connect, and begin using the hardware.

The guide covers hardware setup, software installation, and initial configuration — structured to get users to their first measurement as quickly as possible.
