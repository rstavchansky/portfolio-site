This API migration guide was written to help enterprise customers navigate the transition from earlier versions of the Wowza Streaming Cloud REST API to version 1.3.

The guide covers breaking changes, updated endpoint patterns, and step-by-step migration instructions. It was designed to reduce support burden during the transition period and later became the template for subsequent API version migration content across the documentation set.
