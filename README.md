# Rachael Stavchansky — Technical Writing Portfolio

Personal portfolio site for Rachael Stavchansky, a team manager and experienced technical writer with expertise in technical writing, UX writing, and team management.

## About

Rachael is a technical writer who digs deeply into new technology to surface and document what users need to know. She also crafts concise UI copy with a clear call to action, orienting users without drawing attention to the writing itself. As a manager, she works alongside her team to improve outcomes for product users, documentation readers, and internal stakeholders.
